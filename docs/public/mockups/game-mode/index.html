Rules & provenance

SRD text checked directly. Heat uses 0 / 2 / 4 / 6. Scoundrel XP is an end-of-session review, surfaced at resolution without forcing its timing. Entanglements defaults to illustrative crew heat 4; “Show all” reveals the full table. The upper band is shown as 6+ (the online SRD prints “Heat 6”).

Load limits come from data/games/blades-in-the-dark.json → LoadMaxima.CommitmentMaxBulk: Light 3, Normal 5, Heavy 6. Fine lockpicks are 0 load in the Lurk data. Individual items can also be declared during the score. Choosing a loadout here is an aid, not a hard rule gate.

Crew editors are mock controls only. Only one player should update the crew — check nobody else already has. Crew Rep is skippable to avoid recording the same payoff twice. No live crew data is changed.

The SRD verifies that healing someone else costs no activity for the healer. Gift adjustments and Other are proposed tracker controls, not SRD activity types. The SRD also permits buying an extra activity with 1 rep. No requested rule source was unreachable.
