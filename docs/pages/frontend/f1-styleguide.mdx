## Aesthetic (spec §12)

- **Palette:** ink `#1a1a1a`, paper `#e8e0d0`, blood `#a02c2c`. Dark mode =
  lamplit `#141210` ground with paper-toned text. High-contrast variant
  via `data-contrast="high"`.
- **Type:** League Gothic (heads) → Oswald (labels) → Alegreya Sans (body) →
  Alegreya (notes) → Special Elite (stamps) → IM Fell English (epigraphs).
  Every stack carries a system fallback. Subsets: latin + latin-ext; cyrillic
  retained for Oswald and Alegreya Sans.
- **Texture:** SVG fractal-noise paper grain, heavy rules, stamp motifs.
- **A11y:** `:focus-visible` blood ring, `prefers-reduced-motion` kills
  transitions, manual light/dark/auto + Hi-C toggle in the app bar.

## Fonts & licenses

All files live under `frontend/public/fonts/`. **No hotlinking.** See
`frontend/public/fonts/LICENSE.md` for the per-family table. Five faces are
SIL OFL 1.1; Special Elite is Apache 2.0 (OSI-approved, freely redistributable;
recorded honestly rather than mislabeled OFL). No commercial faces (no Kirsty).

Rebuild the woff2 + `fonts.css` pipeline with:

```bash
cd frontend && python3 scripts/build-fonts.py
```

## Remediation updates (AUDIT-0 waves 7–9)

### Action dots — keyboard use and hit targets (A11Y-01)

- **24×24 px minimum hit target** on every 16px ink dot: an explicitly
  sized 24px `::before` pseudo-element centered with
  `translate(-50%, -50%)` (an `inset` bleed was rejected — the element
  border shrinks the containing block and silently undershoots the target).
  A 10px gap gives a 26px pitch between adjacent dots.
- **Roving tabindex**: the dot group is one tab stop; `ArrowLeft` /
  `ArrowRight` move focus and selection between dots instead of every dot
  being an individual tab stop.
- Effective hit areas are pinned by `action-dots.test.ts` (CSS contract)
  and verified in-browser with `document.elementFromPoint` probes at
  center ±11.5px; measured text contrast on dots: light 13.26:1,
  dark 13.18:1, high-contrast 21:1.

### Theme tokens (THEME-01, THEME-02)

- **`--band-text-muted`** (`var(--paper-sunk)`, `#d6cdb8`): dedicated
  muted-text token for identity text on inked torn-plate bands. Scoped
  resolution for `.character-kicker`, `.crew-kicker`, `.alias`,
  `.crew-type` inside torn-foot plates — light-theme muted colors are never
  reused on dark bands. Pinned ratios (theme01-identity-contrast journey):
  light 8.13:1, Hi-C 11.01:1, dark 12.71:1, dark+Hi-C 11.01:1.
- **`--focus-ring` decoupled from red** (THEME-02): the focus indicator and
  the error border no longer share a color in any theme/contrast
  combination; eight component focus rules resolve
  `var(--focus-ring)` instead of the error red. Pinned by the
  theme02-focus-error journey: 9/9 combos show separable focus vs. error
  borders, 36/36 geometry probes.
