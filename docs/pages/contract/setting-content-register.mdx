# Setting content register

This register records where Doskvol setting names live, what each location is for,
and what remains open. The licence reasoning is in
[Crew world data — licence, scope and sources](./crew-world-sources.mdx).

## Approved shipping data

| Location | Contents | Status |
| --- | --- | --- |
| `data/world/doskvol.json` | 48 faction rows and all 12 districts, with original summaries and 27 sourced noteworthy locations with original short descriptions | CREW-WORLD-03 corrects the CREW-WORLD-02 transcription; human-approved free fan project. |
| `frontend/src/pages/crew-sections/doskvol-world.ts` | Imports the data; renders the stock faction picker and named, described district locations | CREW-WORLD-02, extended by CREW-WORLD-03 |
| `frontend/src/pages/about-licence.ts` | Launch-screen About & licence aside with attribution and links | Shipped by CREW-WORLD-02 |

Rules for shipped data:

- District summaries and location descriptions are **written for this app** from
  verified setting facts, not generated from tier/hold or copied from the book.
- Only confirmed canonical place names are included. Each district has two or
  three; uncertain names and fan-created additions were omitted.
- The official Factions sheet's **entire twelve-row Citizenry block** identifies
  the districts. Whitecrown (Tier V, strong) belongs here, not in the stock
  faction picker. The remaining four sheet groups contain 48 faction rows.
- Choosing a stock faction fills the manual entry only. Saved crew records are
  the user's own.

## Canonical place-name checks

The official [Factions sheet v8.2](https://bladesinthedark.com/sites/default/files/sheets/blades_sheets_v8_2_Factions.pdf)
was rendered and checked visually: its Citizenry column includes Whitecrown and
the other eleven districts. The core book's district gazetteer and the official
[Player's Kit v8.2](https://bladesinthedark.com/sites/default/files/blades_playerkit_v8_2.pdf)
provide the place names and setting facts below. Descriptions are original
paraphrases; no source PDF, map or book passage is shipped.

| District | Included locations | Name reference |
| --- | --- | --- |
| Whitecrown | Doskvol Academy; Dusk Manor Club; Spiregarden Theater | Player's Kit city map and vice list |
| Brightstone | Centuralia Club; Silver Swan | Player's Kit vice list |
| Charterhall | Charterhall University; Charter Wall | Core book, printed p. 262 |
| Six Towers | House of the Weeping Lady; Golden Plum | Player's Kit vice list |
| Silkshore | Red Lamp; Silver Stag | Player's Kit vice list |
| Nightmarket | Harping Monkey; The Veil | Player's Kit vice list |
| Crow's Foot | Crow's Nest; Red Sash Sword Academy; Leaky Bucket | Core book p. 266; Player's Kit vice list |
| The Docks | The North Hook Company; Catcrawl Alley | Core book p. 268; Player's Kit vice list |
| Barrowcleft | Barrow Bridge; Barrowcleft Market | Core book p. 256 |
| Coalridge | Coalridge Mine; The Old Rail Yard; Traven's Smoke Shop | Core book p. 264; Player's Kit vice list |
| Charhollow | Charhollow Market; Strangford House | Core book p. 260 |
| Dunslough | Ironhook Prison; Dunvil Labor Camp | Core book p. 270 |

Location `sources` identify the official kit or the
[published core book](https://evilhat.com/product/blades-in-the-dark/);
the publisher link is a bibliographic reference, not a claim that its product
page contains the gazetteer. The core-book spellings **Dunvil Labor Camp** and
**Red Sash Sword Academy** take precedence over variant fan-map labels.

An additional fan district reference was consulted for cross-checking but mixes
in alterations. It is not the authority for shipped names or descriptions.
The attribution and the excluded-setting licence decision remain unchanged.
